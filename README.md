# 3d-print-prep

Check a finished CAD part for printing: valid solid, walls, fit, orientation, supports and verified export.

This is an agent skill: `SKILL.md` tells an AI coding agent such as Claude Code when to use it and which steps to follow.

## Install

```bash
git clone https://github.com/alinvarat/skill-3d-print-prep.git ~/.claude/skills/3d-print-prep
```
